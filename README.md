# Arabic Translator 🇸🇦➡️🇬🇧

This project is an **Arabic-to-English translator** built using a **Transformer model from scratch in PyTorch**.  
It includes a **custom tokenizer** tailored for Arabic text to improve translation quality.

## ✨ Features

- Translates Arabic text to English
- Built from scratch using PyTorch (no pre-trained models)
- Custom tokenizer for accurate input handling
- Compatible with large input sequences
- Trained on paired Arabic-English datasets

## 🧠 Model

- Architecture: Transformer (Encoder-Decoder)
- Framework: PyTorch
- Tokenization: Custom rules and vocabulary
- Output: Translated English sentence

## 🚀 Usage

1. Input: Arabic sentence  
2. Model: Runs through Transformer  
3. Output: English translation

## 📁 Files

- `transformer_ara_eng_custom_tokenizer.pth`: Trained model weights (tracked with Git LFS)
- `tokenizer.py`: Custom tokenizer logic
- `model.py`: Transformer implementation
- `translate.py`: Translation script

## ⚙️ Requirements

- Python 3.8+
- PyTorch
- Git LFS
